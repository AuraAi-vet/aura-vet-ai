# Aura Vet AI

Aura Vet AI is a groundbreaking veterinary services app that bridges the gap between pet owners and veterinarians. It combines a vibrant community, breed and health scanners, and an AI assistant called "RuRu" to help everyone provide the best care for their pets.

---

## 🚀 Key Features

✅ **Pet Community & News**  
✅ **Breed & Health Identification with AI**  
✅ **RuRu AI Assistant – Multilingual & Accessible**  
✅ **Emergency Alerts & Vet Contact**  
✅ **Accessible Design – Large Fonts, Voice Navigation**  
✅ **Auto Monitoring (Hosted on Vercel)**

---

## 🏗️ How to Use

1️⃣ Download or clone this repository.  
2️⃣ Open the project folder in VS Code or your favorite text editor.  
3️⃣ Make changes if you want (like text, images).  
4️⃣ Upload to GitHub as a repository.  
5️⃣ Deploy to Vercel for free hosting (vercel.com).
